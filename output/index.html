The picture to keep

A multiple integral adds local contributions across a region. Before calculating, draw a representative piece, find its physical area or volume, and sweep it through the region to read the bounds.

  • Rectangular tiles: dA = dx dy.
  • Polar tiles: dA = r dr dθ. The angular edge has length r dθ.
  • Cylindrical blocks: dV = r dr dθ dz.
  • Spherical blocks: dV = ρ² sinφ dρ dφ dθ. Here φ is measured down from +z.
  • General transformations: multiply by the absolute Jacobian determinant.
  • Surface graphs: dS = √(1 + fₓ² + fᵧ²) dA.

Pause and try

1. Reverse the bounds: 0 ≤ x ≤ 1, x² ≤ y ≤ x.

0 ≤ y ≤ 1, y ≤ x ≤ √y. Draw a horizontal strip; the line is the left edge and the parabola is the right edge.

2. Find the volume below z = 1 − x² − y² above the unit disk.

Use polar coordinates. Integrate (1 − r²)r for 0 ≤ r ≤ 1 and 0 ≤ θ ≤ 2π. Answer: π/2.

3. Find the surface area of z = x + y above the unit square.

Both partial derivatives are 1, so the area multiplier is √3. Multiply by the base area of 1: √3.

4. A unit square has density 1 + x. Where does it balance?

Mass is 3/2. The x moment numerator is 5/6, so x̄ = 5/9. Symmetry in y gives ȳ = 1/2.

5. Why is there sinφ in spherical volume?

At polar angle φ the latitude circle has radius ρ sinφ, so its short angular edge has length ρ sinφ dθ. Multiply by ρ dφ and dρ.
